# Shortcuts

The game's Select button is a shortcut that holds one item or spell. This makes it five, and any of them can hold an item, an attack spell or a support spell.

## Use

- **Assign:** open **Equipment**, choose the Select button row (**Hotkeys** with keyboard labels), pick an item or spell and answer Yes. A second list asks which shortcut it goes on and shows what each one holds now. Shortcut 1 is the game's own Select shortcut, set exactly as before. Picking the list's Remove entry clears a shortcut.
- **Use:** press the shortcut's key or button. It works exactly like pressing Select, so MP, the magic gauge, item counts and "use it on what's in front of you" all still apply.

| Shortcut | Keyboard | Controller |
|---|---|---|
| 1 (the game's Select) | 1 | Select |
| 2 | 2 | D-pad Up |
| 3 | 3 | D-pad Down |
| 4 | 4 | D-pad Left |
| 5 | 5 | D-pad Right |

Shortcut 1's key presses Select for you, so the game's controls need no change. The pad's own Select button always works too.

## Settings

| Setting | Default | What it does |
|---|---|---|
| In-game labels | Keyboard keys | What the shortcut list shows beside each shortcut: its key, or its controller button. Keyboard keys also renames the Equipment page's Select button row to Hotkeys. |
| Each shortcut's key | 1-5 | Click it, then press the new key (Esc cancels). A key already used by another shortcut moves over. |
| Each shortcut's controller button | Select, d-pad | D-pad Up/Down/Left/Right, L3, R3, Misc or none. |
| D-pad directions used by a shortcut don't walk or turn | On | In the world only. Menus still scroll with the d-pad, and the sticks are untouched. |

Shortcuts 2-5 are kept with each memory-card save, like the game's own Select shortcut. A new game clears them. Quick saves don't carry them.

## With the Text and Retranslation mods

Not needed, but used when they're on. All the shortcut list's text is drawn through the game's own menu text routine, and item and spell names are taken straight from the game's memory. So the Text mod's fonts, lowercase, spacing and shadows apply, and Retranslation's names show as it translated them. The mod's own words (Hotkeys, Shortcuts, Empty and the key names) are in normal case when the Text mod is on and in capitals when it isn't. A translation can reword them through the Text mod's string table: `shortcuts:hotkeys`, `shortcuts:shortcuts` and `shortcuts:empty`.
