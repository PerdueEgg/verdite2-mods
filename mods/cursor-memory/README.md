# Cursor Memory

King's Field 3 style menu cursors.

## Install

Copy the `cursor-memory` folder into Verdite2's `mods` folder and switch **Cursor Memory** on in the Mods panel.

## What it changes

- **Items and Magic pages** open on the entry you last had highlighted. The cursor follows the item or spell itself, so it stays on the same thing when the list changes; if that entry is gone, it stays on the same row.
- **Equipment sub menus** (weapon, armour, accessories, attack magic and the second slot) open on what is equipped. An empty slot opens on the first row, as the game does.

## Settings

Each of the three can be switched off on its own: the Items page, the Magic page, and the Equipment sub menus.
