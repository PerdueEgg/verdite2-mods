# NPC Dialogue

King's Field 3 style conversations.

## Install

Copy the `npc-dialogue` folder into Verdite2's `mods` folder and switch **NPC Dialogue** on in the Mods panel.

## What it changes

- While an NPC's line is up, **Interact** (Cross) goes straight to their next line, and **Cancel** (Circle) ends the conversation.
- At the end of their dialogue, Interact repeats the last line until you cancel, as talking to them again would.
- NPCs that open a menu after talking (shopkeepers, the fortune teller) are left as they are.

## Settings

| Setting | Default | What it does |
|---|---|---|
| No animations between lines | On | The NPC stays in their talking pose until the conversation ends, then the return animation plays once. Off: every line plays both animations. |
| Cancel does not open the menu | On | The game closes a line on any button, and Cancel is also the menu button, so ending a conversation with it would open the menu a moment later. |
