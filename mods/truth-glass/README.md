# Truth Glass Hotkey

A hotkey that uses the Truth Glass on whatever is in front of you.

## Install

Copy the `truth-glass` folder into Verdite2's `mods` folder and switch **Truth Glass Hotkey** on in the Mods panel.

## Use

Press **`** (the key left of 1) in the world. It is exactly as if you had chosen the Truth Glass from the item menu, without the menu: the game's own enemy, NPC or place description. Anywhere the game would not open its menu, nothing happens.

## Settings

- **Key:** ` by default, or None.
- **Pad button:** none by default; Back, L3, R3 or Misc.
- **Only when carrying the Truth Glass:** off by default. Off, the hotkey works without the Truth Glass and does not give you one.
